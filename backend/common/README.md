# Common

Contains only types, errors, and base utilities genuinely shared by multiple backend modules.

When you don't yet know where a feature belongs, do not drop it straight into `common/`; first confirm which business module it belongs to, so this directory does not turn into a junk drawer.

---

## 中文

只保存确实被多个后端模块共同使用的类型、错误和基础工具。

功能暂时不知道放在哪里时，不能直接放入 `common/`；应先确认它属于哪个业务模块，避免这里演变成杂物目录。
