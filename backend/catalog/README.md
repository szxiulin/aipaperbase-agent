# Catalog

Responsible for raw list import, data validation, data versioning, the unified paper entity, and metadata querying.

It does not handle trend analysis, PDF processing, embedding, or answer generation. Other modules obtain consistent paper facts through this module and must not each maintain duplicate paper objects of their own.

---

## 中文

负责原始清单导入、数据校验、数据版本、统一论文实体以及元数据查询。

不负责趋势分析、PDF 处理、Embedding 和生成回答。其他模块通过本模块获得一致的论文事实，不能各自维护重复论文对象。
