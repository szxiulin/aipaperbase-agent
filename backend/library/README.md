# Library

Responsible for selecting the download scope, estimating disk space, downloading PDFs, validating files, deduplication, storage, and structured parsing.

This module turns papers into reliable local document assets; chunking, embedding, vector indexing, and Q&A belong to `rag/`.

---

## 中文

负责选择下载范围、空间预估、PDF 下载、文件校验、去重、保存和结构化解析。

本模块把论文变成可靠的本地文档资产；切分、Embedding、向量索引和问答属于 `rag/`。
