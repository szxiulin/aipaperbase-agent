# Library

Responsible for selecting the download scope, estimating disk space, downloading or importing PDFs, validating files, deduplication, storage, and local readiness status.

This module turns papers into reliable local document assets; PDF parsing, chunking, embedding, vector indexing, and Q&A belong to `rag/`.

---

## 中文

负责选择下载范围、空间预估、PDF 下载或导入、文件校验、去重、保存和本地就绪状态。

本模块把论文变成可靠的本地文档资产；PDF 解析、切分、Embedding、向量索引和问答属于 `rag/`。
