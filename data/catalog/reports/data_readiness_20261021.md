# 数据库可用性与修复边界

截止：2026-10-21。数据库版本：catalog-20261021T091000Z-04ffa9eba273。开发版使用，未同步公开版。

## 当前结论

可以进入下一轮分类，并用于日常论文检索、资料管理和已有分类的领域地图。当前没有发现破坏记录归属、旧 ID 或资料完整性的阻塞问题。全库正式出版完备性仍未证明；按年份或来源做严格出版统计时必须使用底表范围，不能把本地总量当成出版总量。

这是标题、作者、摘要等元数据数据库，不代表所有论文全文都已下载、解析或建立全文向量。地图只统计已有分类；待分类论文仍可检索。付费模型和全文解析服务本轮未调用，不能把本轮验证当成它们的实时服务验收。

## 本轮实际修复

- TVCG 出版年 2026 的官方 CSV 777 条与页面总数一致，逐条 DOI 和去格式题名匹配，无确认漏收。包含 692 条期刊卷期记录、85 条 Early Access；751 条属于现有研究论文范围，26 条已标记非研究材料继续排除。
- 补入 67 条来源记录摘要，去重主记录缺失减少 64 篇（3,769 → 3,705）。未覆盖非空摘要，未缩短已有作者名单。此次导出未能补上额外的缺失作者。
- 对齐 32 条官方题名，主要处理 HTML 格式标记及大小写、标点差异。保留全部旧 ID、实体关系、已有分类和资料。
- 以前 4 条 IEEE 正式页面未核验记录中，2 条 TVCG 现由官方导出核实；其余 2 条 TPAMI 仍未知。另有特定 ICML 异常批次的 3 条出版身份待核验，不能混作这 2 条。
- 212 条首次在线发表年是 2025、出版社出版年是 2026。两种日期分别记录，原清单年和 ID 不变；未按年份差异重复新增。
- 修正底表证据中“已匹配 ID”的范围：只给实际接受的来源记录，不把其他来源中同题名的候选也当成确认记录。同步刷新各年度缺失字段计数。

## 能修复的问题

| 问题 | 当前影响 | 处理方式 |
|---|---|---|
| 部分摘要、作者为空 | 影响摘要检索及题名模糊时的分类；大多数缺作者集中于 EMNLP（956 篇） | 有可验证免费来源或可用机构来源时补齐；按 DOI/原始 ID 和题名核对，保留来源。当前缺口不阻塞其他论文使用。 |
| 16,087 篇未分类 | 地图覆盖不全，领域检索不能代表全部新增论文 | 下一轮按固定清单分类；先处理有摘要组。作者为空不单独阻止主题分类。 |
| 128 对重复实体候选 | 可能影响少量去重统计；候选不是确认重复 | 单独保留复核，确认后通过旧 ID 兼容机制处理；不自动合并或丢弃资料。关联到分类队列的记录进入先复核组。 |
| 部分题名仍含格式标记 | 影响显示和模型输入 | 分类清单已生成去格式题名并记录输入哈希；原始记录保留。可继续做有证据的格式清理，无须重采整个数据库。 |
| 首发年、卷期年与原采集年不同 | 年度出版统计存在混合口径 | 有官方日期的分别保存；全局迁移要先取得跨年正式清单并设计 ID 兼容，不能按 DOI 年号猜测。 |

## 当前无法补齐的部分

| 限制 | 原因 | 保留方式与使用边界 |
|---|---|---|
| ACM 完整正式目录 | 公网目录返回 403，浏览器停在安全验证页，机构入口未加载成功 | 应收总量留空，保留原因。现在无法证明全收齐，也不据此删掉已有记录。 |
| IEEE 其他年度及首发年全量目录 | 已有机构权限取得一个完整出版年子集后，继续访问被浏览器权限检查拒绝 | 不绕过或改走其他浏览器路径。已有 777 条证据可使用，其余目录总量未知。重新获准访问后有机会继续修复，并非数据永久损坏。 |
| 来源未公开、未提供的作者或摘要 | 当前可用证据没有这些字段 | 留空。不能通过生成一段摘要或猜测作者来声称补齐。 |
| 2026 全年完整性及尚未正式出版论文的出版信息 | 年份尚未结束，部分来源只有录用/预出版名单 | 冻结到 2026-10-21，不补未来信息；录用、预印本和正式出版状态分开解释。 |
| 人工评测级分类准确率 | 当前 97.0% 来自 399 篇 AI 代理复核，非独立人工金标 | 不将其表述为人工准确率，也不套用到下一轮新增标签。 |

访问限制和证据缺失是本轮边界，不是继续反复重采就能消除的问题。数据库交付不再以这些空白全部消失为前提。
