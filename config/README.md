# Config

Keeps public configuration that users or maintainers may modify and that must be version-controlled.

- `venues/`: conferences, journals, years, tracks, and rating ranges;
- `arxiv/`: arXiv core categories and extended categories;
- `topics/`: default research topic definitions;
- `models/`: optional configuration for parsing, embedding, reranking, and generation models.

Secrets, personal paths, and private settings must not go here; keep them in local user configuration.

---

## 中文

这里保存用户或维护者可以修改、且需要纳入版本管理的公共配置。

- `venues/`：会议、期刊、年份、轨道和评级范围；
- `arxiv/`：arXiv 核心分类与扩展分类；
- `topics/`：默认研究主题定义；
- `models/`：解析、Embedding、重排和生成模型的可选配置。

密钥、个人路径和私有设置不得放在这里，应保存在本地用户配置中。
